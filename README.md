# adonis
 Adonis - Frameword Backend

 ## Préŕequisitos

    Node.js ≥ 24.x
    npm ≥ 11.x



## Criar Projeto - https://docs.adonisjs.com/installation

npm create adonisjs@latest [project-name] -- --kit=api

Explicação site oficial: Kit Inicial de API . 

Uma configuração de monorepo com dois aplicativos: um backend AdonisJS e um projeto frontend vazio onde você pode configurar
 qualquer framework frontend de sua escolha (TanStack Start, Nuxt, Next.js ou outros). 
 Segurança de tipos de ponta a ponta e tipos de transformadores compartilhados já estão configurados entre o backend e o frontend.

Esse projeto será vinculado a um projeto Nuxt 3 no Frontend, o Adonis já disponibiliza criar o projeto com configuração API
